CLEAR ROBOTICS — PREMIUM NEXT.JS WEBSITE

See README-LOCAL.md for installation and startup instructions.

This package contains:
- Next.js 16 / React 19 / TypeScript frontend
- Tailwind CSS 4, Framer Motion and Lucide React dependencies
- All 30 original website pages routed at their original .html URLs
- Original images and media assets
- Preserved Node.js enquiry API and JSON persistence
- Contact form integrated with the local enquiry API

Start: npm install && npm run dev
Frontend: http://localhost:3001
API health: http://localhost:3001/api/health
