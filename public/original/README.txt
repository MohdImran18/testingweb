DEPLOYMENT
1. Extract the ZIP.
2. Upload all HTML files and the assets folder together into the website root (for example public_html).
3. Keep filenames and the assets folder structure unchanged.
4. Set index.html as the default homepage.

FUNCTIONAL NOTES
- Header links, service/product cards and internal project links are local HTML links.
- WhatsApp and Call floating actions use the current configured contact number +852 5138 5925. Confirm the number before publishing.
